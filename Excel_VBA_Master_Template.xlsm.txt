CSV FORMAT - AUTOLISP COMPATIBLE:
=============================================================================

Import Format (from AutoCAD):
Block Name, X Coordinate, Y Coordinate, Z Coordinate, Layer, Color, Linetype

Export Format (to AutoCAD):
Block Name, X Coordinate, Y Coordinate, Z Coordinate, Layer, Color, Linetype

=============================================================================
WORKFLOW:
=============================================================================

1. IMPORT PHASE:
   - AutoCAD exports blocks → CSV file
   - Excel imports CSV → Macro Library
   - Data includes: Block name, coordinates (X,Y,Z), layer, color, linetype

2. FILTER PHASE:
   - User sets criteria in Project_Config
   - Formula-based filtering populates Selected Macros
   - Filter by: Category, voltage level, panel type, location

3. EXPORT PHASE:
   - Generate Drawings button clicked
   - Selected Macros → CSV export (AutoLISP format)
   - AutoCAD launch trigger created

4. AUTOCAD IMPORT PHASE:
   - User opens AutoCAD drawing
   - Runs MACROMANAGER command
   - Imports CSV → Blocks placed at exact coordinates

SETTINGS CONFIGURATION:
=============================================================================

Settings Sheet (Column B):
B2:  Macro Library Path      - Folder containing macro CSV files
B4:  Project Name             - Current project identifier
B6:  Export Path              - Where to save exported CSV files
B8:  CSV Files Path           - Default CSV file location
B10: Logs Path                - Where to save log files
B12: Block Library Path       - AutoCAD block library location
B14: Auto Launch AutoCAD      - Yes/No (auto-launch on export)

Hidden Column F stores persisted values.

INSTALLATION STEPS:
=============================================================================

1. Create new Excel workbook, save as .xlsm (macro-enabled)

2. Create 5 sheets with EXACT names:
   - Macro Library
   - Selected Macros
   - Project_Config
   - Settings
   - Logs

3. Press Alt+F11 (VBA Editor)

4. Import all 7 modules:
   - File → Import File → Select each .bas module
   - Or copy/paste code into new modules

5. Add References:
   - Tools → References
   - Check: Microsoft Scripting Runtime
   - Check: Microsoft Office Object Library

6. Run initialization:
   - Alt+F8 → InitializeWorksheetReferences → Run

7. Set up headers:
   - Alt+F8 → SetupMacroLibraryHeaders → Run
   - Alt+F8 → SetupSelectedMacrosHeaders → Run

8. Configure Settings tab:
   - Set all paths in column B
   - Click Save Settings button

9. Add form buttons:
   - Developer → Insert → Button (Form Control)
   - Assign macros as listed above

10. Test with sample data:
    - Alt+F8 → Test5_CreateSampleData → Run
    - Verify data appears in Macro Library

ERROR HANDLING:

Common Issues:
--------------
1. "Subscript out of range" → Sheet name mismatch
2. "User-defined type not defined" → Missing references
3. "Can't find project or library" → Check references for MISSING items
4. "File not found" → Check Settings paths

=============================================================================
COORDINATE SYSTEM:
=============================================================================

Format: X, Y, Z (decimal format: 0.00)
- X: Horizontal position
- Y: Vertical position  
- Z: Elevation (usually 0 for 2D)

Example: 100.50, 200.75, 0.00

Precision: 2 decimal places maintained throughout

=============================================================================
AUTOCAD INTEGRATION:
=============================================================================

AutoCAD Commands:
-----------------
MACROMANAGER  - Open macro manager dialog
UCB           - Alias for MACROMANAGER
NETLOAD       - Load .NET application (if needed)

Import Process in AutoCAD:
---------------------------
1. Open target drawing
2. Type: MACROMANAGER or UCB
3. Switch to Import tab
4. Select "Circuits" content type
5. Browse to exported CSV file
6. Click "Start Import"
7. Blocks placed at specified coordinates
