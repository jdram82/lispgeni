# CSV FORMAT SPECIFICATION - 12 COLUMN EXCEL-AUTOCAD INTEGRATION

## Overview
This document specifies the 12-column CSV format used for bidirectional data exchange between AutoCAD (via UnifiedManager_Auto.lsp) and Excel (via VBA macros).

---

## CSV Format Structure

### Header Row (Required)
```
Block/Circuit Name,Category,DWG File Location,X Coordinate,Y Coordinate,Z Coordinate,Layer,Color,Linetype,Export Date,Export Time
```

### Column Definitions

| Column # | Header | Data Type | Description | Example | Required |
|----------|--------|-----------|-------------|---------|----------|
| 1 | Block/Circuit Name | Text | Name of block or circuit assembly | `PowerPanel_MCC01` | Yes |
| 2 | Category | Text | Functional category | `Power` | Yes |
| 3 | DWG File Location | Path | Full path to exported DWG file | `C:\Projects\Electrical\PowerPanel_MCC01.dwg` | Yes |
| 4 | X Coordinate | Number | X position in drawing units | `100.5000` | Yes |
| 5 | Y Coordinate | Number | Y position in drawing units | `200.7500` | Yes |
| 6 | Z Coordinate | Number | Z elevation (usually 0 for 2D) | `0.0000` | Yes |
| 7 | Layer | Text | AutoCAD layer name | `POWER` or `0` | Yes |
| 8 | Color | Number/Text | AutoCAD color index | `256` (ByLayer) | Yes |
| 9 | Linetype | Text | AutoCAD linetype | `ByLayer` | Yes |
| 10 | Export Date | Date | Date of export | `2025-11-19` | Yes |
| 11 | Export Time | Time | Time of export | `14:30:45` | Yes |

---

## Data Format Rules

### Coordinates (Columns 4-6)
- **Format**: Decimal number with 4 decimal places
- **Precision**: `0.0000`
- **Example**: `100.5000`, `200.7500`, `0.0000`
- **Units**: AutoCAD drawing units (typically millimeters or inches based on INSUNITS)

### Category (Column 2)
**Predefined Categories:**
- `General`
- `Control_Panel`
- `Motor_Circuit`
- `Power_Distribution`
- `Lighting_Circuit`
- `Instrumentation`
- `Communication`
- `Safety_System`
- `HVAC_System`
- `Custom` (user-defined)

### Layer (Column 7)
- **Format**: Valid AutoCAD layer name
- **Default**: `0` (if not specified)
- **Examples**: `POWER`, `CONTROL`, `WIRING`, `SYMBOLS`

### Color (Column 8)
- **Format**: AutoCAD Color Index (ACI) number
- **Range**: 0-256
- **Common Values**:
  - `256` = ByLayer (recommended)
  - `7` = White/Black
  - `1` = Red
  - `3` = Green
  - `5` = Blue

### Linetype (Column 9)
- **Format**: Valid AutoCAD linetype name
- **Default**: `ByLayer` (recommended)
- **Common Values**: `ByLayer`, `CONTINUOUS`, `DASHED`, `HIDDEN`, `CENTER`

### Date/Time (Columns 10-11)
- **Date Format**: `YYYY-MM-DD` (ISO 8601)
- **Time Format**: `HH:MM:SS` (24-hour)
- **Example**: `2025-11-19` and `14:30:45`

## Excel Implementation

### Macro Library Sheet
**Sheet Name**: `Macro Library`

| A | B | C | D | E | F | G | H | I | J | K | L |
|---|---|---|---|---|---|---|---|---|---|---|---|
| Sl.No | Block/Circuit Name | Category | DWG File Location | X Coordinate | Y Coordinate | Z Coordinate | Layer | Color | Linetype | Export Date | Export Time |
| 1 | PowerPanel_MCC01 | Power | C:\Projects\... | 100.5000 | 200.7500 | 0.0000 | POWER | 256 | ByLayer | 2025-11-19 | 14:30:45 |

**Notes**:
- Column A (Sl.No) is auto-generated by Excel, NOT in CSV
- Columns B-L map directly to CSV columns 1-11

### Selected Macros Sheet
**Sheet Name**: `Selected Macros`
- **Same structure** as Macro Library
- Populated via formulas or manual filtering
- Used for exporting filtered selection back to CSV

## AutoCAD LSP Implementation

### Export Function
**File**: `UnifiedManager_Auto.lsp`
**Function**: `ucb:save_to_csv`

```lisp
(ucb:save_to_csv 
  item_name          ; Block/Circuit Name
  category           ; Category (prompted from user)
  dwg_file           ; Full path to exported DWG
  base_pt            ; (X Y Z) coordinate list
  insert_pt          ; (not used, pass base_pt)
  content_type       ; "blocks" or "circuits"
  csv_path           ; Output CSV file path
  layer_name         ; Layer from entity
  color_val          ; Color from entity (as string)
  linetype_val)      ; Linetype from entity
```

### Import Function
**File**: `UnifiedManager_Auto.lsp`
**Function**: `ucb:read_csv`

Parses CSV and returns list of items:
```lisp
((name category dwg x y z layer color linetype date time) ...)
```

## Validation Rules

### Required Fields
All 11 columns MUST have values. Empty fields will cause import errors.

### Coordinate Validation
- Must be numeric
- Should have 4 decimal places
- Must not contain commas or special characters

### Path Validation
- DWG File Location must be valid path (absolute or relative)
- File does not need to exist for CSV export (created during AutoCAD export)
- File MUST exist for AutoCAD import

### Category Validation
- Should match predefined categories
- Custom categories are allowed
- No special characters except underscore

## Common Issues & Solutions

### Issue 1: Coordinates Not Preserved
**Symptom**: Blocks placed at wrong location after import
**Solution**: Ensure coordinates use 4 decimal places and are not rounded

### Issue 2: Missing Layer/Color/Linetype
**Symptom**: Blocks appear with default properties
**Solution**: Verify CSV includes Layer (column 7), Color (column 8), Linetype (column 9)

### Issue 3: CSV Parse Error
**Symptom**: Excel fails to import CSV
**Solution**: 
- Check for commas in data fields (should be quoted if present)
- Verify header row matches exactly
- Ensure all 11 columns present in each row

### Issue 4: Date/Time Format Mismatch
**Symptom**: Date appears as number in Excel
**Solution**: 
- Use YYYY-MM-DD format for dates
- Use HH:MM:SS format for times
- Set Excel column format to Date/Time

## Round-Trip Workflow

### Phase 1: Export from AutoCAD
1. Select blocks/circuits in AutoCAD
2. Run `UCB` or `UNIFIEDMANAGER` command
3. Select category from dropdown
4. Pick base point (coordinate 0,0,0)
5. LSP extracts Layer/Color/Linetype from selected entities
6. LSP saves 11-column CSV with full DWG path

### Phase 2: Import to Excel
1. Open Excel template
2. Click "Import from CSV" button
3. VBA reads CSV and populates Macro Library (adds Sl.No column)
4. 12 columns displayed: Sl.No + 11 CSV columns

### Phase 3: Filter in Excel
1. User sets criteria in Project_Config sheet
2. Formulas or manual selection populate Selected Macros
3. Selected Macros maintains same 12-column structure

### Phase 4: Export from Excel
1. Click "Generate Drawings" button
2. VBA exports Selected Macros (minus Sl.No) to CSV
3. CSV has same 11-column format as original export

### Phase 5: Import to AutoCAD
1. Run `UCB` or `UNIFIEDMANAGER` command
2. Switch to Import mode
3. Browse to Excel-exported CSV
4. LSP reads CSV and places blocks at exact coordinates
5. Layer/Color/Linetype properties restored

## File Naming Convention

### Exported DWG Files
- Format: `{BlockName}.dwg` or `{CircuitName}.dwg`
- Location: `{Library Folder}\{Category}\{Name}.dwg`
- Example: `C:\Circuit_Library\Power\PowerPanel_MCC01.dwg`

### CSV Files
**AutoCAD Export** (default):
- `circuits.csv` or `blocks.csv` in library folder

**Excel Export** (project-specific):
- Format: `Project_Macros_{ProjectName}.csv`
- Example: `Project_Macros_Building_A_Electrical.csv`
- Location: Export Path from Settings

## Version Compatibility

| Component | Version | CSV Format |
|-----------|---------|------------|
| UnifiedManager_Auto.lsp | Auto | 12-column (11 CSV + Sl.No in Excel) |
| Excel VBA Template | 3.1 | 12-column |
| UnifiedManager_v2.4.lsp | 2.4 | 8-column (legacy) |

**Note**: UnifiedManager_v2.4 uses 8-column format (Block Name, X, Y, Z, Layer, Color, Linetype, File Path). Not compatible with Excel template.
